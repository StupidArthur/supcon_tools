# 算法发布工具 v1.2 用户手册

模拟"运维逐个进平台手动点发布/改核数/改副本/改 CPU·GPU"这件事：用一张 CSV 写清单，工具并发批量执行。

产物：`算法发布工具v1.2.exe`（单文件 exe，无需装 Python）。

---

## 1. 这是什么

把平台里每个算法的 **5 个字段**——发布/不发布、核数、副本数、CPU·GPU、算法名称——抽出来，放进一张 CSV 里点一次按钮批量改完。本质上替代的是「在 alg-manager-web 平台上一遍遍点编辑、改字段、保存」的手工活。

工具影响的字段（其它字段一律不动）：

| CSV 列 | 平台字段 | 取值范围 |
|---|---|---|
| `算法名称` | `zhName` | 字符串，大小写不敏感 |
| `是否发布` | `isRelease` | `是`（发布）/ `否`（不发布） |
| `核数` | `cores` | 浮点，空 = 用平台已有值 |
| `副本数` | `numReplicas` | 整数，空 = 用平台已有值 |
| `发布位置` | `resourceType` | `CPU`（→1）/ `GPU`（→2），空 = 用平台已有值 |

CSV 里出现但**平台里没建**的算法名会列入「已发现差异」清单，**不会**自动在平台建算法（要建得先在平台后台手动建好）。

---

## 2. 怎么使用

### 2.1 启动

双击 `算法发布工具v1.2.exe`。窗口标题：`算法发布工具 v1.2  |  designed by @yuzechao`。

### 2.2 一次完整的发布流程

1. **放 CSV** — 把 `publish_list_*.csv` 放到 exe 同级目录（文件名以 `publish_list_` 开头方便工具自动识别）。
2. **填连接信息** — 在「连接配置」区填 URL / Username / Password / 并发数。
3. **点「开始发布」**（绿色按钮）。
4. **看弹窗确认差异** — 工具自动登录、拉全量算法、和 CSV 比对，弹出"确认发布"对话框，列出：
   - 已发现差异（核数/副本数/位置与平台不一致）
   - 待发布列表
   - 已发布（无需操作）
   - CSV 设不发布但平台已发布（建议取消发布）
5. **点确定** — 工具按"并发数"分批发布，批内并行、批间串行。
6. **看日志** — 「发布日志」区实时输出每步的 ✓ / ✗ 和错误信息；发布完成会自动重新拉全量算法校验每个算法的 `isRelease`，标出失败项。

### 2.3 停止 / 中断

工具没有「中止」按钮。点了「开始发布」之后只能：
- 关窗口——后台线程会跑到当前批结束才停；
- 或者等日志显示「全部发布成功」/ 失败清单后算结束。

### 2.4 CSV 没自动加载怎么办

启动时工具会扫 exe 同目录里 `publish_list_*.csv`，自动选**最新修改时间**的一份。如果一份都没扫到，CSV 输入框是空的，需要点「浏览」手动选。

## 3. 需要填写什么

「连接配置」区 4 个字段：

| 字段 | 默认值 | 必填 | 备注 |
|---|---|---|---|
| **URL** | `http://10.16.11.1:31501` | 是 | 平台 alg-manager-web 的 HTTP/HTTPS 地址 |
| **Username** | `admin` | 是 | 平台账号 |
| **Password** | （空） | 是 | **每次启动都要重新填**，不会记忆 |
| **Tenant ID** | （空，仅 HTTPS 显示） | HTTPS 必填 | URL 是 `http://` 时输入框会自动隐藏，不用填 |
| **并发数** | `3` | 是 | 每批同时发几个发布请求，必须是正整数 |

URL 改了之后输入框会触发——`http://` 模式下 Tenant ID 输入框自动隐藏，`https://` 模式下自动显示。隐藏不代表不传，只是默认值已够。

## 4. 需要准备什么附件

### 4.1 CSV 文件

文件名：**建议以 `publish_list_` 开头**（如 `publish_list_20260423.csv`），这样工具启动时自动加载。

列名：**必须精确匹配**这 5 个中文名：

```
算法名称,是否发布,核数,副本数,发布位置
```

编码：工具依次尝试 `utf-8-sig` → `utf-8` → `gbk` → `gb18030`，**一般直接用 UTF-8 保存就行**。

### 4.2 一份可用的 CSV 示例

直接复制保存为 `publish_list_demo.csv`：

```csv
算法名称,是否发布,核数,副本数,发布位置
DeepAGI,否,0,0,GPU
deepSearch,是,1,1,CPU
view_data,是,1,1,CPU
valve_anomaly_detection_train,是,2,1,GPU
reconstruct_redesign,是,3,2,CPU
```

### 4.3 字段填写细节

- `算法名称` —— 匹配平台 `zhName`，**大小写不敏感**（CSV 里写 `deepsearch` / `DeepSearch` / `DEEPSEARCH` 都行）。**严格区分**大小写的是 `是否发布`，不能写 `yes / no / true / false`，必须中文「是」「否」。
- `是否发布 = 否` —— 工具**不会**自动取消已发布算法的发布，只是把它列在「CSV设置不发布但平台已发布」清单里等你手动决定；点确定时实际**不会**对它执行任何操作。
- `核数 / 副本数 / 发布位置` 留空 —— 用平台已有的值；填了就以 CSV 为准（与平台不一致时差异列里会标出）。

## 5. 界面上怎么看、怎么判断该做什么

工具窗口分 4 块，从上到下：

### 5.1 「CSV 配置」区

- 显示当前加载的 CSV 文件路径。
- 启动时自动加载 exe 同目录**最新修改的** `publish_list_*.csv`，加载完会在「发布日志」里打 `[加载] CSV 已加载: N 条记录 (编码: utf-8-sig)`。
- 想换一份点「浏览」。

**怎么看**：路径对了 + 日志里「CSV 已加载」就说明 CSV 解析成功。如果路径显示但日志里**没有**加载记录，多数是编码识别失败，需要把 CSV 用记事本「另存为 UTF-8」再试。

### 5.2 「连接配置」区

详见第 3 章。

### 5.3 「开始发布」按钮

绿色。点了之后：

- 按钮变灰（防止重复点）。
- 日志开始打 `[连接成功] 缓存 N 个算法`。
- 自动弹出「确认发布」对话框。

### 5.4 「确认发布」对话框（这是判读的关键）

弹窗里有 5 块，**每一块都要扫一遍**再决定要不要点确定：

| 块 | 怎么读 | 怎么判断 |
|---|---|---|
| **已发现差异** | 标红的是核数 / 副本数 / 位置不一致的算法；绿色「无」表示没差异 | **CSV 写错了**才应该有差异；如果看起来不对，停手回去改 CSV |
| **已发布（无需操作）** | 平台已发布且 CSV 也是「是」的 | 不用管 |
| **待发布** | CSV 是「是」、平台未发布 → 这批工具会去发布它 | 数一下对不对，对才能确定 |
| **CSV设置不发布但平台已发布** | CSV 是「否」、平台还在发布 → 工具**不会**自动取消，只列出来提醒 | 想取消得自己进平台手动操作 |
| **确认是否开始发布 (N 个)** | N = 待发布数量 | N=0 时工具不会做任何操作 |

点「确定」→ 按并发数分批并发执行；点「取消」→ 整个任务停掉，回到主窗口。

### 5.5 「发布日志」区

实时输出，每批一个块：

```
[批次 1/3] 正在发布: ['deepSearch', 'view_data', 'valve_anomaly_detection_train']
  ✓ deepSearch 发布成功
  ✓ view_data 发布成功
  ✓ valve_anomaly_detection_train 发布成功
[批次 1/3] 完成

[批次 2/3] 正在发布: [...]

[发布] 批次发布完成，等待最终校验...
[校验] 重新获取平台算法列表...
  ✓ deepSearch 已发布成功
  ✓ view_data 已发布成功
  ✗ valve_anomaly_detection_train 发布失败或状态异常
============================================================
[校验完成] 1 个未发布成功:
  - valve_anomaly_detection_train
============================================================
```

**怎么判读**：

- `✓ xxx 发布成功` — 当前批内的发布请求返回成功。
- `✗ xxx 发布失败: <错误>` — 该算法本次没发出去，看错误信息：`登录已过期` → 重启工具重新登录；`权限不足` → 换账号；其它 → 通常是该算法当前正在被另一流程占用，可重试。
- `[校验] xxx 已发布成功 / 发布失败或状态异常` — 工具发布完又重新拉了一次算法列表二次确认，能区分「接口返回成功但实际没生效」的情况。**这是真正能信的结果**——只看批里的 `✓` 不够，必须看到 `[校验完成]`。

「(可能是登录已过期，请重新登录)」是工具对鉴权类响应码（A0201/A0202/A0203/A0230）的识别，看到这条就重启工具重新填密码。
